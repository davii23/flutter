# Flutter Lab Exercises 4, 5 and 7

Three standalone Flutter Web projects, prepared from the matching Alien4, Alien5 and Alien7 repository examples.

## Projects

- `Exercise4_Assets_Media` - asset image grid. Includes the required image asset and `pubspec.yaml` declaration.
- `Exercise5_Navigation_Routing` - Home -> Profile -> Details named-route navigation.
- `Exercise7_State_Serialization` - Student model, JSON-map conversion, `StatefulWidget`, and `setState()`.

## Run any project

Open PowerShell in the selected project folder (the folder containing `pubspec.yaml`) and run:

```powershell
flutter pub get
flutter run -d chrome
```

These projects are set up for the user's Chrome workflow. They do not require Android Studio or Android SDK to run in Chrome.
