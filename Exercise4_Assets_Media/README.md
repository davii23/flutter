# Exercise 4 - Utilize the Assets and Media

This project follows the Alien4 example: it displays two copies of an image with `Image.asset()` inside a two-column `GridView`.

The original repository specifies `assets/images/flutter.png` but does not include the image itself. This package supplies an original sample image at that path and declares it in `pubspec.yaml`.

## Run in Chrome

```powershell
flutter pub get
flutter run -d chrome
```
