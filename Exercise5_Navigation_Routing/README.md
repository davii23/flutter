# Exercise 5 - Implementation of Navigation and Routing

This project follows Alien5 and uses three Dart files:

- `lib/main.dart` - home screen and named route table.
- `lib/profile.dart` - profile screen, which navigates to details.
- `lib/details.dart` - details screen, which returns with `Navigator.pop()`.

## Run in Chrome

```powershell
flutter pub get
flutter run -d chrome
```
